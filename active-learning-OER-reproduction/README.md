# 复现笔记：主动学习指导发现四金属钙钛矿析氧电催化剂

对 Nature Materials 论文 **"Active learning guides discovery of a champion four-metal perovskite oxide for oxygen evolution electrocatalysis"** 的逐步骤复现尝试，重点是**非实验部分**（数据处理、图神经网络、集成、主动学习选样）。

原论文：Moon, J. et al. *Nature Materials* **23**, 108–115 (2024). doi:[10.1038/s41563-023-01707-w](https://doi.org/10.1038/s41563-023-01707-w)
作者仓库：[JunseokMoon/OER2022](https://github.com/JunseokMoon/OER2022)

---

## 这个仓库想回答什么

1. 这篇论文的机器学习流程，到底每一步在算什么？
2. 哪些部分**只要按论文写的就能精确复现**？
3. 哪些部分**因为作者没公开关键细节而无法复现**，缺的到底是什么？

结果分成两类：**能精确复现的（数据侧）** 和 **只能做定性复现的（模型侧）**。

## 复现状态总览

| # | 环节 | 状态 | 依据 |
|---|---|---|---|
| 1 | 数据表验收（30/40/10131/10141 行） | ✅ 精确 | 四张表全部通过一致性检查 |
| 2 | 图结构（336 节点 / 1296 条键） | ✅ 精确 | 600 + 800 个 PDB 全部解析一致 |
| 3 | XRD 编码（7 峰 ×2，归一化） | ✅ 精确 | 第 2 峰恒为 1.000，与 SI 描述一致 |
| 4 | 候选空间（10,101 = 1,824 + 8,277） | ✅ 精确 | 三个数与论文完全吻合 |
| 5 | 主动学习选样（K-means + 覆盖度） | ✅ 定量吻合 | 覆盖度改善 32.0% vs 论文 33.3% |
| 6 | 网络结构（层数、维度、顺序） | ⚠️ 部分 | 从 checkpoint 反推，形状全部对上 |
| 7 | 用作者权重前向推理 | ❌ 不精确 | 30 个样本**逐个都对不上**，见下文 |
| 8 | 从零训练到 corr≈0.882 | ❌ 未达成 | 最好一次 30 点 corr = 0.496 |
| 9 | 候选打分与 2.87% 通过率 | ❌ 未做 | 缺 XRD 生成模型权重（仓库为空目录） |

**一句话结论：论文里不依赖模型的部分能精确复现；依赖模型权重和训练细节的部分做不到。**

## 五个核心发现

### 1. 候选空间被精确复现

从作者给的候选表里数出来的：

```
总行数        10,131 = 30 个训练样本 + 10,101 个候选
≤4 金属候选    1,824     ← 论文：1,824
≥5 金属候选    8,277     ← 论文：8,277
```

三个数字一个不差，说明作者表就是论文那个空间。

### 2. 图结构的解析是确定的

```
节点  336 = 36 个 A 位 + 60 个 B 位 + 240 个氧
有向边 1,296（A–O 576 条 + B–O 720 条）
无向边去重 648
```

600 个初始图 + 800 个最终图，全部一致。

### 3. 主动学习选样能定量复现

只用公开的 t-SNE 坐标，不需要模型：

| 指标 | 补样前 | 补样后 | 论文 |
|---|---|---|---|
| 四金属候选到最近训练点的平均距离 | 0.0937 | 0.0637 | 0.081 → 0.054 |
| 改善幅度 | — | **32.0%** | **33.3%** |

绝对值和论文差约 15%（作者的 t-SNE 参数未公开），但**相对改善几乎一致**，说明选样逻辑复现对了。

### 4. 从 checkpoint 能反推网络结构，但反推不到计算细节

从权重形状能唯一确定：

```
节点特征 4 维 → 补零到 64 维
4 步消息传递：边特征(3) → Dense → 64×64 边矩阵 × 邻居向量 → GRUCell(64)
读出：MultiHeadAttention(1 头, key_dim=64) → 2×LayerNorm + FFN(64→128→64) → 平均池化
融合：128(图) + 64(强度) + 64(峰位) + 16(t-SNE) = 272
回归头：272 → 512 → 256 → 1
```

**但这些形状对得上，不等于计算对得上。**

用作者的 5 个折模型预测 30 个训练样本，与作者公布的 seed-0 预测值比对：

```
逐个精确匹配（<1e-4）：0 / 30
中位最小误差：约 0.02 V
我们的预测与作者预测的相关系数：0.45 ~ 0.66
```

如果前向计算完全正确，同一条数据、同一份权重应该给出**完全相同**的数。0/30 说明还差某个环节（很可能是节点特征的归一化方式，或消息聚合的方向）。

> 早期我们曾看到 P01 预测 0.5463、作者 0.5348，以为只差 0.0115 V 就证明成功了。**那是巧合**，30 个样本一起看才暴露问题。

### 5. 不确定度会系统性地骗人

自己训了 5 个模型做集成，在 5 个留出样本上：

```
集成预测的 RMSE        = 0.0909 V
集成不确定度（σ）      = 0.0125 V
```

**RMSE 是 σ 的 7 倍**，即模型严重过度自信。而论文的筛选判据正是"σ < 0.020 V 就送去做实验"——按这个标准，这 5 个样本会**全部通过**，而它们的真实误差是 91 mV。

这就是为什么论文的 F4 栏（外推与 OOD 验证）写着"未做跨体系外推"：**小 σ 不等于准确，可能只是所有模型一起错。**

## 从零训练为什么没到 0.882

试了六种配置（都在 25 个训练样本 / 5 个验证样本上）：

| 实验 | 配置 | 结果 | 诊断 |
|---|---|---|---|
| step_11 | 1296 边，batch 5，60 轮，无 dropout | 30 点 corr **0.496**，RMSE 0.0553 | 略好于基线 0.0586 |
| step_12 | 同上，300 轮 | 训练 MSE 降到 1e-4，验证 corr 掉到 0.45 | **过拟合** |
| step_13 | 加 dropout 0.3，300 轮 | 后期 corr 0.59 vs 0.42 | dropout 有效但不够 |
| step_14 | dropout 0.3，120 轮，5 种子集成 | corr 0.526，σ 低估 7 倍 | 误差高度相关，集成无效 |
| step_16 | 50400 条边 vs 1296 条边，60 轮 | 两者都低于"猜平均值"基线 | 未收敛，无法比较 |
| — | 论文：700 轮 × 10 种子 × 6 折 = 60 个模型 | **0.882** | 训练量是我们的 20–40 倍 |

没做到的三个原因，按重要性排：

1. **训练量不够** —— 论文是 60 个模型 × 700 轮，本地跑要 40 小时，我们只跑了 60–300 轮。
2. **数据增广缺失** —— 论文每个样本有 20 个随机金属占位结构，每轮换一个；我们固定用 `_00.pdb`。
3. **实现细节未公开** —— 特征归一化、学习率、早停规则、折的具体成员都没有写。

## 快速开始

### 1. 环境

```powershell
conda create -n oer2022 python=3.10 -y
conda activate oer2022
pip install -r requirements.txt
```

如果 `conda activate` 在 PowerShell 里不可用，直接用 `run.bat`（里面写死了解释器路径，按自己的改一行即可）。

### 2. 下载作者的大文件

```powershell
powershell -ExecutionPolicy Bypass -File fetch_assets.ps1
```

### 3. 按顺序跑

```powershell
python audit_data.py                 # 期望：5 行 PASS
python step_03_build_graph.py        # 期望：(336,4) / (2,1296) / (1296,3)
python step_08_visualize.py          # 出两张图到 figures/
python step_09_forward_walkthrough.py # 跟着看一次前向
python step_18_selection.py          # 主动学习选样，几秒出结果
```

模型相关的脚本（step_10 ~ step_17）耗时较长，按需跑：

| 脚本 | 耗时 | 需要 GPU？ |
|---|---|---|
| step_10 | 约 12 分钟（3 种子 × 60 轮） | 否 |
| step_11 | 约 22 分钟 | 否 |
| step_12 | 约 18 分钟 | 否 |
| step_14 | 约 37 分钟 | 否 |
| step_16 | 对照组 5 分钟 + 实验组 65 分钟 | 否 |
| step_17 | 约 25 分钟（50 候选 × 20 模型） | 否 |

## 已知无法复现的部分

| 缺什么 | 影响 |
|---|---|
| **XRD 生成模型权重** | 作者仓库 `initial_generation/checkpoint/` 是空目录，候选无法获得 XRD 输入。我们用零向量替代（实测偏差约 0.02 V） |
| **130 个候选的预测值**（Supplementary Data 1） | 仓库没有，无法对照通过率 2.87% |
| **随机种子列表** | 无法复现具体的 10 个预测值 |
| **每折的成员划分** | 同上 |
| **节点特征归一化方式** | 疑似导致前向无法精确对齐（0/30） |
| **学习率、早停、激活函数选择** | 训练曲线无法对齐 |

## 给想复现的人的建议

1. **先跑 step_18。** 它是唯一能精确对上论文数字的环节（32% vs 33%），几秒钟出结果，先建立信心。
2. **不要指望从零训到 0.882。** 除非你有 40 小时的机器时间和全部未公开细节。
3. **checkpoint 能加载 ≠ 能复现。** 一定要用「多个样本 + 精确匹配」验证，不要用单个样本沾边就下结论。
4. **不确定度必须校验。** 拿 RMSE/σ 比一下，远离 1 就说明模型过度自信，此时 0.020 V 阈值会筛出垃圾。
