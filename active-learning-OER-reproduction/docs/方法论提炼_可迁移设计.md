# 方法论提炼：这篇论文里哪些设计可以搬到别处

论文：Nature Materials 23, 108–115 (2024)
定位：不是为了复现数字，而是为了抄它的**设计决策**。

阅读方式：每一节回答三个问题——
① 它解决了什么问题；② 换到你的体系，留什么、改什么；③ 什么时候这套会失效。

---

# 第 1 层｜问题定义：它到底在解什么

## 1.1 这条流水线的适用前提

这套方法的骨架是：

```
可枚举的候选空间  ×  廉价的代理表示  ×  可实验验证的统一标签
        ↓
   少量已知样本训练模型
        ↓
   在候选空间上打分 + 评估不确定性
        ↓
   挑"信息量最大"的样本做实验
        ↓
   扩数据、重训、再筛
```

三个前提缺一不可：

| 前提 | 本文怎么满足 | 缺失会怎样 |
|---|---|---|
| 候选空间可穷举 | 5 金属 × 步长 0.2 → 10,101 | 空间太大就只能采样，不确定性估计失真 |
| 有廉价表示 | 2×2×2 超胞图 + 元素属性 | 每个候选都要 DFT，闭环成本爆炸 |
| 标签口径统一 | 全部是 η₁₀ (V)，同一套电化学协议 | 跨文献拼数据 → 标签噪声吞掉信号 |

**换成你的体系，先自查这三条。** 任何一条不成立，就不该照抄，要先改造。

## 1.2 它真正的创新点在哪

不是"用 MPNN 预测性能"——这在 2023 年已经不新鲜。

真正的三个创新：

1. **把不确定性当成一等公民**，并用"实验误差"给它定标（见第 3 层）。
2. **用生成模型补全缺失模态**，让闭环能自己跑（见第 2.3 节）。
3. **用"已知但未测"的文献材料做主动学习的样本**，同时保证合成可行（见第 4.2 节）。

复现时如果只抄了 MPNN，等于没学到东西。

# 第 2 层｜表示设计：多模态怎么拼

## 2.1 三种输入各自承担什么

| 输入 | 维度 | 承载的信息 | 不可替代性 |
|---|---|---|---|
| 结构图 | 336 节点 × 4 特征 | 局域配位、元素在哪个位点 | 唯一能表达"位点占位"的模态 |
| XRD | 14 维（7 强度 + 7 峰位） | 长程有序、相结构 | 唯一能表达"实际晶体结构"的模态 |
| 组成 → t-SNE | 2 维 | 成分在化学空间中的位置 | 让"成分"变成连续坐标 |

**可迁移的第一条原则：**

> 多模态不是"多喂点特征"，而是每个模态负责一种别的模态表达不了的信息。

如果你的体系只有成分（比如合金成分），那就不需要图，也不需要 XRD——直接成分 + 元素描述符就够。**不要为了像论文而硬造模态。**

## 2.2 t-SNE 当输入：一个值得偷的技巧

大多数人会把 10 维成分直接拼进网络。本文先把成分用 t-SNE 压成 2 维，再进 Dense(16)。

这么做的效果：

- 让"成分相似性"变成**连续的几何距离**，而不是 10 维稀疏向量；
- 模型的成分分支只需要学一个 2 维流形上的函数，参数效率高；
- 副作用是 t-SNE 必须**在全体候选上 fit**，否则训练集和候选集的坐标系不一致。

**[坑]** t-SNE 是非参数、不可外推的。新样本必须用同一次 fit 的坐标系 transform，不能重新 fit。

**可迁移原则：**

> 当某个离散输入（成分、配方、工艺参数组合）本身有"相似性结构"，可以考虑先降维成连续坐标再喂模型。
> 但降维必须在**全体候选空间**上做，不是只在训练集上做。

替代方案：PCA（可外推）、UMAP（更快）、自编码器（可外推）。t-SNE 的优点是保留局部结构，缺点是完全不可外推。

## 2.3 生成模型补全模态：闭环的关键

论文最实际的一个工程决策：

> 候选材料的 XRD 拿不到，因为拿 XRD 就得先合成。

所以他们训了一个**从组成 + 图 → XRD** 的生成模型（其实是回归，输出 14 维）。

然后用配对 t 检验证明：用模拟 XRD 和用实验 XRD，预测结果**统计等价**（p = 0.48）。

**这是整篇论文最值得抄的一段。**

因为它回答了一个通用问题：

> 如果某个模态在筛选阶段拿不到，怎么办？

三条路：
1. 训练时就不要这个模态（损失信息）；
2. 用物理模拟替代（需要第一性原理，贵）；
3. **训一个代理模型，并用统计检验证明等价**（本文选择）。

**可迁移原则：**

> 任何"实验才能拿到的输入"，都可以用代理模型替代；
> 但替代前必须做等价性检验（配对 t 检验 / 分布检验），否则你不知道闭环里累积的是误差还是信号。

# 第 3 层｜不确定性：本文最容易被误读的部分

## 3.1 它的"不确定度"不是贝叶斯不确定度

$$\sigma_i=\text{std}\left(\hat\eta_i^{(1)},\dots,\hat\eta_i^{(10)}\right)$$

来源只有三个随机性：

1. 金属原子在超胞里的随机占位；
2. 数据划分（10 个种子）；
3. 模型初始化。

**它衡量的是"预测对随机性的敏感度"，不是"模型有多确信"。**

这意味着：

- 它**不能**告诉你"这个预测错了多少"；
- 它**能**告诉你"这个区域的模型稳不稳"；
- 对远离训练分布的点，它**可能给出很小的小σ**（模型一致地错）——这是这套方法最大的隐患。

**[坑]** 本文没有做 OOD 检验（F4 那栏就是"未做跨体系外推"）。你自己用的时候，要补一个"到训练集最近距离"作为第二道闸。

## 3.2 用实验误差给不确定性定标

$$\sigma_{\text{threshold}} = \min_i\left(\text{std of experimental repeats}\right)=0.020\ \text{V}$$

只有当预测不确定度低于"实验本身的分辨率"，继续算才有意义。

**这是全文最漂亮的一个设计。**

因为它把"模型要多准"这个模糊问题，变成了一个**由实验决定的客观标准**：

> 模型的不确定度 < 实验误差 → 再算下去是浪费
> 模型的不确定度 > 实验误差 → 先补数据

**可迁移原则：**

> 不要拍脑袋定"可接受的误差"。用你实验平台的重复性标准差当阈值。
> 这个数字天然合理，而且写进论文时不用解释。

## 3.3 分布校正：一个容易被忽略的补丁

$$X_{\text{corrected}}=\left(\frac{X-\mu_{\text{pred}}}{\sigma_{\text{pred}}}\right)\sigma_{\text{exp}}+\mu_{\text{pred}}$$

为什么需要它：模型预测的分布宽度往往和实验分布不一样（通常更窄，模型过度自信）。这个式子把预测分布强行拉成实验分布的形状。

**注意这是有争议的操作**——它用了实验分布的信息，严格说是"用了标签信息"。本文用它来做筛选可视化，但没有用它来报告的精度指标。

**可迁移原则：**

> 任何"用标签分布做后处理"的操作，都要明确说明它不参与精度评估，否则就是数据泄漏。

# 第 4 层｜主动学习：选样的三条判据

## 4.1 它没有选"预测最好"的

这是初学者最常犯的错：以为主动学习就是挑预测性能最好的候选去验证。

本文的做法相反：

> 目的是**降低整个空间的不确定性**，不是找一个更低的过电位。

原文说得很直白："our aim was not to prioritize the identification of a candidate with a lower overpotential, but instead to reduce the prediction uncertainty evenly throughout the entire structural space"。

## 4.2 三条选样判据（可迁移）

**判据一：簇内均衡**

30 个样本分 4 簇为 (8, 9, 8, 5)，标准差 1.50；补 10 个后为 (11, 10, 9, 10)，标准差 0.71。

$$\text{std}=\sqrt{\frac{1}{k}\sum_j (n_j-\bar n)^2}$$

**判据二：覆盖度**

1,824 个四金属候选到最近训练点的平均距离，0.081 → 0.054。

$$d_{\text{avg}}=\frac{1}{N}\sum_c \min_i \|\mathbf{t}_c-\mathbf{t}_i\|_2$$

**判据三：在低维投影上分散**

用 t-SNE 平面目视确认新点落在空白区。

## 4.3 最省的一招：补的样本是"已知但未测性能"的文献材料

补的 10 个氧化物（LaFeO₃、LaCoO₃、LaNiO₃…）都有两个特点：

1. 文献里报道过合成，**合成可行**；
2. 文献里**没有** OER 过电位，所以对模型是"新标签"。

这样既扩了数据，又不冒合成失败的风险。

**可迁移原则：**

> 主动学习的第一批补充样本，不要选模型最兴奋的未知材料。
> 选"已知能做得出来、但没测过目标性质"的材料——这是风险最低、信息量又不小的选择。

# 第 5 层｜验证链：怎么让别人相信你

本文的验证是分层的，这个层次结构值得抄：

| 层次 | 做法 | 防什么 |
|---|---|---|
| 输入消融 | OS / SO / SS 三种打乱（O=原始，S=打乱） | 证明每个模态都有贡献 |
| 代理等价 | 实验 XRD vs 模拟 XRD，配对 t 检验 p=0.48 | 证明生成模型可替代 |
| 分布检验 | Shapiro–Wilk p=0.133 | 证明 t 检验的前提成立 |
| 双相一致性 | Pnma / Pbcm 各筛一次，都是第 1 | 证明结论不依赖相的选择 |
| 实验复核 | CPCF 预测 0.396，实测 0.391±0.004 | 最终闭环 |

**可迁移原则：**

> 消融不是"去掉一个模块看掉多少分"，而是"把某个模态打乱看掉多少分"。
> 打乱（shuffle）比删除（drop）更好，因为保持了输入维度不变，排除架构差异。

## 5.1 打乱的具体做法（很巧）

对 XRD：把某个峰的强度换成 [0,1] 均匀随机数，并按升序排列（因为原始峰位是升序的）。

这样做保持了"7 个值、升序、在 [0,1]"这些结构性质，只破坏了"这个值对应这个材料"的对应关系。

**可迁移原则：**

> 消融时，随机化要**保持分布的形状**，只破坏与标签的关联。
> 否则你测的是"分布外输入"，不是"信息缺失"。

# 第 6 层｜解释层：从"能预测"到"为什么"

## 6.1 置换重要性

$$\Delta_f=\left|\hat\eta(\mathbf{x})-\hat\eta(\mathbf{x}^{\text{shuffled}}_f)\right|$$

关键细节：**原子特征不是简单打乱列，而是跨样本错配。**

比如测"离子半径"的重要性：把元素 X 的半径，配上元素 Y 的组成信息。这样测的是"半径-元素对应关系"的重要性。

**可迁移原则：**

> 当特征之间有强耦合（半径天然绑定元素），简单打乱列会破坏物理一致性。
> 要设计"保持一致性、只破坏目标关系"的置换方式。

## 6.2 SHAP 交互

$$\delta_{ij}(S)=f(S\cup\{i,j\})-f(S\cup\{i\})-f(S\cup\{j\})+f(S)$$

"空原子"= 4 维特征全零向量。这是图模型特有的技巧：**用零向量表示"这个位点没有金属"**。

**可迁移原则：**

> 图模型做特征归因时，"缺失"需要一个合法的表示。
> 零向量（或 learnable mask token）比"删掉节点"更可控，因为保持了图结构。

# 第 7 层｜换成你自己的体系：填空模板

下面这张表，是你要做的事。左边是论文的做法，右边留给你填。

| 环节 | 论文做法 | 你的体系 |
|---|---|---|
| 候选空间 | 5 金属 × 步长 0.2 = 10,101 | ？ |
| 目标量 | η₁₀ (V)，同协议测量 | ？ |
| 结构表示 | 2×2×2 超胞图，336 节点 | ？ |
| 元素特征 | 半径、电负性、位点标识 | ？ |
| 谱学特征 | 7 峰 × (强度, 位置) | ？ |
| 成分嵌入 | 10 维 → t-SNE 2 维 | ？ |
| 缺失模态替代 | XRD 生成模型 + t 检验 | ？ |
| 不确定度来源 | 结构随机 + 划分 + 初始化 | ？ |
| 不确定度阈值 | 0.020 V（最小实验误差） | ？ |
| 选样判据 | 簇均衡 + 覆盖度 + 投影分散 | ？ |
| 首批补充样本 | 文献已知但未测性能 | ？ |
| 消融方式 | 按模态打乱 | ？ |
| 最终验证 | 实验闭环 | ？ |

## 7.1 三个最容易被忽略的决策点

1. **候选空间怎么离散化**：步长 0.2 是实验可做性的下限（再多元素比例就合成不准了）。你的步长应该由**合成精度**决定，不是由算力决定。

2. **标签的口径必须唯一**：本文所有 η₁₀ 都来自同一个实验室、同一套 RDE 协议。如果你从文献里拼数据，不同论文的测试条件差异（负载量、电解液、iR 补偿）会带来 0.05 V 级别的系统偏差——比模型误差还大。

3. **不确定度阈值要先测**：在开始任何建模之前，先做 5 次重复实验，测出你自己的重复性标准差。这个数字会直接决定你整个闭环的停止条件。

## 7.2 什么时候这套方法不适用

- 候选空间无法枚举（比如蛋白质序列）；
- 单个样本的标签成本 > 一个月（闭环轮次跑不动）；
- 标签噪声 > 目标信号（比如目标差异 0.02 V，但实验重复性 0.05 V）；
- 没有廉价的结构/表示（每个候选都要 DFT 一周）。

第四条最重要：这套方法的全部经济性，来自"候选打分几乎免费"。

# 第 8 层｜你该从代码里学什么

不是学"怎么写 MPNN"（网上教程多得是），而是学这三件事：

## 8.1 怎么验证自己对输入的理解

看 `step_05_variant_test.py`、`step_06_radius_probe.py`、`step_07_selfloop_probe.py`。

它们的共同结构：

```
列出 N 种可能的实现方式
        ↓
每种都跑一遍，输出一个标量
        ↓
和已知的 ground truth 比
        ↓
选残差最小的那个
```

这个模式可以搬到任何"不确定别人怎么实现"的场景。

**关键**：ground truth 必须来自别人的产出（这里是作者发布的 checkpoint + 结果 CSV），不能是你自己的另一个实现。

## 8.2 怎么处理"论文没写"的信息

本书的处理方式是三档标记：

```
[已核实]     论文/SI 明写，或本地跑通验证
[已从checkpoint反推]  由权重形状唯一确定
[待核对假设] 论文没写，给默认值 + 给出验证方法
```

**可迁移原则：**

> 复现/设计时，把每个参数标注来源。来源不明的一律进"待验证"清单，并写明用什么实验证伪。
> 这比"我觉得应该是这样"专业得多。

## 8.3 怎么设计验收标准

本文每个环节都有可验的数：

| 环节 | 验收数 |
|---|---|
| 数据 | A/B 位和 = 1，XRD ∈ [0,1] |
| 图 | 336 节点、1296 边 |
| 预测模型 | corr 0.882 / RMSE 0.033 |
| 生成模型 | 位置 RMSE 0.013、强度 0.123 |
| 筛选 | 2.87% → 100% |
| 机理 | 准确率 0.917 |

**可迁移原则：**

> 每写一段代码，先想好"跑出来什么数说明它对了"。想不出来，说明这段代码的接口还没设计清楚。

# 附：一页纸速查

```
【输入】
  图: 节点4特征(半径,电负性,A位,B位)，边3特征(A-O,B-O,A-B)，双向全组合
  谱: 7峰×(相对强度, 2θ/90°)
  成分: 10维 → t-SNE(在全体候选上fit) → 2维

【模型】
  节点特征补零到64 → 4步(边矩阵64×64 × 邻居 + GRUCell)
  → Transformer(1头) → 平均池化 → Dense(128)
  → 拼接[128, 64(强度), 64(峰位), 16(t-SNE)] = 272
  → Dense(512) → Dense(256) → Dense(1)

【训练】
  batch 5, epochs 700, Adam, MSE
  30样本 → 6折×5个；40样本 → 8折×5个
  10个种子 × 5折 = 50次训练 → 每样本10个预测

【不确定度】
  σ = std(10个预测, ddof=1)
  阈值 = 最小实验重复性 = 0.020 V

【筛选】
  候选 10,101（≤4金属 1,824 + ≥5金属 8,277）
  通过率 = #{σ < 0.020} / 总数

【选样】
  KMeans(k-means++, tol=5e-4, max_iter=300)
  判据: 簇均衡 + 覆盖度 + t-SNE分散
  补样: 文献已知合成但未测性能的材料

【验证】
  按模态打乱做消融
  模拟vs实验 配对t检验(p=0.48)
  双相一致性
  实验闭环
```
