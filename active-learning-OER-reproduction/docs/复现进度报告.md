## 二、已确定的网络结构（不再是猜测）

依据：`initial_train/checkpoint/OO_00_full` 的变量形状 + Keras 官方 MPNN 示例

```
输入：node_features(336,4), edge_features(E,3), pair_indices(2,E),
      intensity(7), position(7), tsne(2)

消息传递（重复 4 次）：
    h = pad(node_features, 4 -> 64)          # 补 60 个 0
    bond  = Dense(4096)(edge_features)       # kernel[3,4096] = 3 -> 64x64
    bond  = reshape(bond, (-1,64,64))
    neigh = gather(h, pair_indices[1])       # (E,64)
    t     = matmul(bond, neigh[...,None])    # (E,64)
    agg   = segment_sum(t, pair_indices[0])
    h     = GRUCell(64)(agg, h)              # kernel[64,192]

读出：
    attn = MultiHeadAttention(heads=1, key_dim=64)(h,h,h)
    x    = LayerNorm(h + attn)
    x    = LayerNorm(x + Dense(128,relu) -> Dense(64))
    g    = mean(x, axis=0)                   # 图级平均池化

分支：
    g      -> Dense(128)
    I(7)   -> Dense(64)
    θ(7)   -> Dense(64)
    tSNE(2)-> Dense(16)
    concat = 272

回归头：
    272 -> Dense(512) -> Dense(256) -> Dense(1)
```

4096 = 64×64 的来源：**节点特征先补零到 64 维**，所以 EdgeNetwork 的 atom_dim = 64，
不是 4。这一条如果不看出来，网络根本搭不起来。

## 五、还差的最后一步

### 半径口径枚举结果（step_06_radius_probe.py）

以 fold0、方案B 为基准，靶子 0.534791：

| 半径口径 | 预测 | Δ |
|---|---|---|
| 固定高价态（当前） | 0.546290 | **0.0115** |
| 按电荷中性价态（LaMnO3 → Mn³⁺） | 0.546290 | 0.0115 |
| 半径用 pm（×100） | −0.112661 | 0.6475 |
| 4 特征 z-score 标准化 | 0.566490 | 0.0317 |
| 半径置 0 | 0.549237 | 0.0144 |

结论：

1. LaMnO₃ 按电荷中性算出来 B 位就是 Mn³⁺，和"固定高价态"完全一致，所以两种口径给出同一个数——这也说明**半径不是残差的主要来源**。
2. 半径置 0 时 Δ 只从 0.0115 变到 0.0144，进一步佐证图分支对半径不敏感。
3. pm 单位明确错误（输出跑到负值），说明作者用的是 Å。

因此残差的 0.0115 V 不在半径上，剩下的可能来源按优先级：

1. **t-SNE 输入**：2 维坐标进 Dense(16)，杠杆很大。CSV 里的 `tsne_0/tsne_1`
   是在全部候选上 fit 的结果，perplexity 等参数未公开。
2. **XRD 值**：我们直接用 CSV 里的实验值，但如果作者对 7 个峰做过额外对齐/插值，
   会有 0.01 量级差异。
3. **图级池化**：平均 vs 求和（我用平均，符合 Keras 示例）。
4. **配对方向**：`pair_indices[0]` 收、`[1]` 发，若反了会系统性偏移。
5. **自环**：Keras 示例会给每个节点加自环并用"无键"特征占位，作者可能保留。

建议的下一步排查顺序：先证伪 5（加自环试一次），再试 1（用 sklearn 重跑 t-SNE
换几个 perplexity），最后 4（把 pair 方向翻转）。

### 自环假设检验结果（step_07_selfloop_probe.py）

| 写法 | 边数 | 预测 | Δ |
|---|---|---|---|
| A 无自环，第3列=A–B | 50,400 | 0.546290 | **0.0115** |
| B 有自环，第3列=A–B | 50,736 | 0.551782 | 0.0170 |
| C 有自环，第3列=自环占位 | 50,736 | 0.551782 | 0.0170 |
| D 无自环，第3列=自环占位 | 50,400 | 0.546290 | 0.0115 |

结论：

1. **加自环会让结果变差**（0.0115 → 0.0170），所以作者没有保留 Keras 示例的自环。
2. A 与 D 完全相同，是因为 LaMnO₃ 没有 A–B 键，第 3 列全被 0 缩放，等于没参与。
   所以"第 3 列到底是 A–B 还是自环占位"这一项**用单金属体系测不出来**，
   要用多金属体系（如 P20 = Pr₀.₅Ba₀.₅CoO₃）才能区分。

至此，P01 上的最佳配置锁定为：
**方案 B（50,400 条全组合、双向、无自环）+ Å 单位 Shannon 半径 + 氧带 4 特征**，Δ = 0.0115 V。
